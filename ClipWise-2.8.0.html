Added

  • Protected Secrets: a new Settings pane for keeping a password or other short secret in ClipWise and copying it to the clipboard on demand. Each secret gets its own keyboard shortcut; every use requires Touch ID or your device password; the copy is wiped from the clipboard automatically after a short delay. Secrets never appear in ClipWise's own clipboard history. Ships with a few example entries so the Settings pane isn't empty on first look — delete them any time.

Fixed

  • The Reader's "There is no text to read" error no longer gets stuck on screen forever. "Try Again" used to resend the same empty text and reproduce the identical error every time, with no way to dismiss it; the dialog now offers a way to close it, and the app refuses to open a Reader window for empty text in the first place.
